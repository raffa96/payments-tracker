### Added

- Project setup: TypeScript run natively by Node.js, ESLint, Prettier and the
  Node.js test runner with coverage thresholds.
- Express application skeleton with security headers and a `/health` endpoint.
- Environment-based configuration validated at startup.
- Continuous integration with GitHub Actions and dependency updates with Dependabot.
- Project documentation, contributing guide, code of conduct and security policy.
